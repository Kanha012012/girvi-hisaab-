# गिरवी हिसाब — शुरुआती PWA नमूना

## iPhone पर मुफ्त होस्ट करने का तरीका
1. Safari में github.com खोलें और मुफ्त अकाउंट बनाएं / लॉगिन करें।
2. नया public repository बनाएं, उदाहरण: `girvi-hisaab`।
3. repository में `Add file` → `Upload files` से इस ZIP की तीन फाइलें (`index.html`, `manifest.json`, `sw.js`) अपलोड करें और commit करें।
4. Repository `Settings` → `Pages` खोलें। `Deploy from a branch` चुनें, branch `main`, folder `/ (root)` चुनकर Save करें।
5. Pages का URL तैयार होने पर उसे Safari में खोलें। पहली बार पेज पूरी तरह खुलने दें और इंटरनेट चालू रखें।
6. Safari के Share बटन → `Add to Home Screen` → `Add` दबाएं।
7. ऐप को एक बार खोलकर परीक्षण करें। फिर Airplane Mode में खोलकर जाँचें कि ऐप चलता है या नहीं।
8. `बैकअप / सेटिंग` में जाकर टेस्ट बैकअप डाउनलोड करें और अलग से सुरक्षित रखें।

## जरूरी सीमाएँ
- यह केवल शुरुआती नमूना है, वास्तविक गिरवी कारोबार के लिए सत्यापित लेखा सॉफ्टवेयर नहीं।
- स्थानीय डेटा अभी ब्राउज़र में बिना एन्क्रिप्शन रखा जाता है। PIN/Face ID सुरक्षा शामिल नहीं है।
- ब्याज गणना का मॉडल 30-दिन महीने और सालाना पूंजीकरण का सरलीकृत नमूना है। लीप वर्ष, तारीखों, भुगतान-समायोजन और सालाना पूंजीकरण के वास्तविक नियमों का लेखाकार/विशेषज्ञ से सत्यापन जरूरी है।
- PDF बनाने के लिए खाता विवरण में `रसीद / प्रिंट` दबाकर Print dialog से PDF सेव करने का विकल्प चुनें; iPhone पर Share/Print विकल्प iOS संस्करण के अनुसार अलग हो सकता है।
- वास्तविक ग्राहक डेटा डालने से पहले बैकअप/रिस्टोर, ऑफलाइन, तारीखों और सभी गणनाओं का परीक्षण करें।
